# Greenhouse 网站模仿指南

当你想要实现某个功能或页面时，请严格按照以下流程执行：

## 核心原则

1. **调研优先**：在实现任何功能前，必须先深入调研 Greenhouse 目标网站
2. **设计还原**：追求视觉还原度，参考具体的设计数值
3. **技术适配**：使用 Next.js + Tailwind CSS 进行实现

## 工作流程

### 第一步：需求分析

理解用户想要实现的具体功能，识别该功能在 Greenhouse 网站上的对应页面或模块。

**你需要询问用户**：
- 这个功能对应 Greenhouse 的哪个页面？
- 是否有具体的页面 URL？

### 第二步：目标网站调研（必须执行）

**禁止直接开始实现代码！** 必须先完成以下调研：

#### 2.1 页面结构分析

使用 WebFetch 获取目标页面的完整内容，分析：
- DOM 结构与布局层级
- 关键容器和分区
- 内容组织方式

#### 2.2 视觉设计分析

提取并记录以下信息：
- **配色方案**：主色、辅色、强调色、背景色
- **字体系统**：字体族、大小、权重、行高
- **间距系统**：padding、margin、gap 的具体数值
- **视觉效果**：阴影、圆角、边框、透明度
- **动画效果**：过渡时长、缓动函数、触发条件

#### 2.3 交互行为分析

- 用户交互流程
- 鼠标悬停/点击状态变化
- 响应式断点和移动端适配
- 表单验证和反馈

#### 2.4 功能实现分析

- 组件状态管理方式
- 数据获取和处理方式
- 第三方库和服务

### 第三步：方案制定

基于调研结果，制定实现方案：

**必须包含**：
- 设计还原清单（具体的颜色值、字体大小等）
- 组件划分建议
- Tailwind CSS 配置建议
- 优先级标注（必须还原 vs 可以简化）

### 第四步：代码实现

按照方案进行代码实现，确保：
- 使用 Tailwind CSS 的具体数值还原设计
- 组件拆分合理
- 代码质量高

## 注意事项

- 不要跳过调研步骤直接写代码
- 调研时要尽可能获取具体的设计数值
- 方案要具体到可以直接实现的程度
- 如果目标页面复杂，可以分多次调研和实现
