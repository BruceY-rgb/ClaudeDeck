# Plan 可视化功能实现计划

## 整体架构

本项目包含两部分：

| 部分 | 位置 | 说明 |
|-----|------|------|
| **可视化核心** | 当前项目 (Claude Skills and Agents Manager) | PlansPage 中的可视化组件 |
| **独立服务** | 单独仓库 (plan-viz-web) | 独立的 Web 应用，提供本地端口访问 |

## Part 2: 独立仓库 - plan-viz-web

### 仓库定位

独立的 React Web 应用，运行后开放本地端口（如 `http://localhost:3456`），提供完整的 Plan 可视化功能。

### 技术栈

- React 19 + TypeScript
- Vite
- Reactflow
- Tailwind CSS

### 核心功能

1. **Plan 解析**：读取本地 `.claude/plans/` 目录下的文件
2. **流程图可视化**：交互式展示计划结构
3. **本地服务**：启动后监听本地端口
4. **URL 参数**：支持通过 `?plan=xxx` 指定要可视化的计划

### API 设计

```
GET /                      # 首页，显示计划列表
GET /?plan=<name>         # 直接打开指定计划
GET /api/plans            # 获取计划列表 JSON
GET /api/plan/<name>     # 获取指定计划解析后的 JSON
```

### 启动命令

```bash
npm run dev    # 开发模式，默认端口 3456
npm run build  # 构建生产版本
```

## Part 3: Slash Command

### 文件

`~/.claude/commands/plan-viz.md`

```markdown
# Plan Visualization
可视化计划文件为交互式流程图

## 使用方式
/plan-viz
/plan-viz [plan-name]

## 说明
启动 plan-viz-web 服务并打开可视化界面。
```

### 实现逻辑

1. 检查本地服务是否运行（端口 3456）
2. 如未运行，启动服务
3. 打开浏览器或深度链接到 `http://localhost:3456`
