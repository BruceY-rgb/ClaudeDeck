# Boss 直聘求职者搜索工具 - 开发计划

## 项目概述

开发一个带有 Web GUI 的桌面应用程序，帮助招聘者在 Boss 直聘网站上搜索符合条件的求职者。

## 核心功能

1. **LLM 对话式交互**
   - 类似 ChatGPT/Claude 的聊天界面
   - 支持多会话（左侧边栏管理）
   - 老板用自然语言描述需求
   - Agent 自动理解并执行搜索

2. **候选人展示与选择**
   - 搜索结果以弹出层展示（固定在聊天区域上方）
   - 按匹配程度排序
   - 卡片支持左右滑动浏览
   - 提供列表视图快速查看所有候选人
   - 老板可以点击选择感兴趣的候选人
   - 选中后导出详细个人资料

3. **文件导出与管理**
   - 导出格式：PDF + JSON 都支持（老板可选择）
   - 默认导出路径（作为设置项，一次设置）
   - 右侧边栏文件树显示本次对话导出的所有文件
   - 支持查看已导出文件的路径

4. **用户认证模块**
   - 手机号 + 验证码登录
   - 登录状态自动保存

5. **侧边栏**
   - 左侧边栏：会话管理 + 设置（可折叠）
   - 右侧边栏：文件树（可折叠）

## 技术选型

- **前端**: React + TypeScript + Tailwind CSS
- **浏览器自动化**: agent-browser (Native 模式)
- **状态管理**: React Context / Zustand

## 确认的技术方案

1. **登录方式**: 程序启动 headed 模式的浏览器，用户自己在浏览器中打开 Boss 直聘并登录，程序检测到登录成功后自动获取 cookies 并保存
2. **滑块验证**: 用户在程序启动的浏览器中自行完成
3. **自然语言理解**: 直接使用 LLM (Claude API) 解析用户需求
4. **搜索数量**: 初始获取 20 个候选人，支持获取更多
5. **核心功能**: 搜索 + 导出（首要），优先实现候选人搜索和列表展示
6. **数据存储**: Web 页面实时显示搜索结果（不持久化存储）
7. **部署方式**: Web 服务（后端 + 前端）

## 技术栈

- **前端**: React + TypeScript + Tailwind CSS
- **UI 风格**: 参考 claude.ai（简洁、圆角卡片）
- **主题**: 支持深色/浅色模式切换
- **图标**: Lucide React（来自 Next.js 官方推荐）
- **后端**: Node.js + Express + Socket.IO
- **浏览器**: agent-browser (Native CDP 模式)
- **实时通信**: WebSocket（浏览器画面同步）
- **部署**: 支持远程访问（配置端口和防火墙）

---

## 注意事项

1. **Claude API Key**: 需要在 .env 中配置 ANTHROPIC_API_KEY
2. **agent-browser**: 需要确保已安装并在 PATH 中
3. **安全性**: 生产环境需要添加 API 认证机制
4. **HTTPS**: 远程访问建议配置 HTTPS 证书
5. **端口**: 前端 3000，后端 3001（可配置）

## 实现步骤

### 第一步：修改登录流程（当前任务）

#### 1.1 修改前端登录界面
- 移除手机号验证码输入框
- 添加"打开 Boss 直聘并登录"按钮
- 添加登录状态检测和提示

#### 1.2 修改后端登录 API
- 添加 `POST /api/login/open-browser` - 启动 headed 模式浏览器，打开 Boss 直聘首页
- 添加 `GET /api/login/check-status` - 检测浏览器中的登录状态（轮询）
- 修改现有登录 API 的逻辑

#### 1.3 登录流程
1. 用户点击"打开 Boss 直聘并登录"按钮
2. 后端启动 headed 模式的浏览器，打开 https://www.zhipin.com
3. 前端显示"请在浏览器中登录 Boss 直聘，登录成功后会自动检测"
4. 前端每 3 秒调用检测 API
5. 检测到登录成功后，获取 cookies 并保存
6. 更新前端登录状态

### 第二步：后端核心功能

1. **浏览器管理服务**
   - 启动/停止 agent-browser（headed 模式）
   - 浏览器状态管理
   - 会话保存/恢复（使用 --session-name 参数）

2. **登录 API**
   - `POST /api/login/open-browser` - 打开浏览器让用户登录
   - `GET /api/login/check-status` - 检测登录状态
   - `GET /api/login/status` - 检查登录状态

3. **搜索 API**
   - `POST /api/search` - 执行搜索
   - `GET /api/candidates` - 获取候选人列表

4. **WebSocket 服务**
   - 浏览器画面实时同步
   - 滑块验证时的人工介入通知

### 第三步：前端界面

> 使用 **frontend-developer** agent 实现前端界面

1. **LLM 对话式主界面**（类似 ChatGPT）
   - 聊天消息区域（展示对话历史）
   - 输入框（老板自然语言描述需求）
   - 发送按钮

2. **候选人展示区域**
   - 卡片式候选人列表
   - 显示基本信息：姓名、职位、经验、薪资
   - 点击卡片可查看/选择

3. **侧边栏**
   - 左侧边栏：会话管理 + 设置（可折叠）
     - 设置包含：默认导出路径、主题切换（深色/浅色）
   - 右侧边栏：文件树（可折叠）
     - 点击文件可预览内容（PDF/JSON）

4. **登录弹窗**
   - 手机号输入 + 验证码
   - 滑块验证提示

### 第四步：浏览器自动化

1. **LLM 需求解析**
   - 用户输入自然语言需求
   - 调用 Claude API 解析为结构化 JobRequirement
   - 返回解析结果给前端确认

2. **登录流程**
   - 启动 headed 模式浏览器（可视）
   - 用户输入手机号 → 后端填入网站
   - 用户输入验证码 → 后端填入
   - 触发滑块验证 → 用户在弹出浏览器中完成
   - 保存登录状态（cookies）

3. **搜索流程**
   - 根据解析的需求自动输入搜索词
   - 翻页获取 20 个候选人
   - 解析页面提取候选人信息

4. **数据提取**
   - 姓名、职位、经验、薪资、位置、技能标签
   - 计算匹配度分数

5. **结果返回**
   - 返回候选人列表给前端展示
